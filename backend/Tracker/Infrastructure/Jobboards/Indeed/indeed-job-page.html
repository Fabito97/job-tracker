Background

We are looking for a Backend Developer to join the Resource Mobilization product team, within the Technology and Transformation for Operations (TTD/TTO) unit. Our product vision is to enable the Bank's resource mobilization capabilities through modern, secure, and scalable digital solutions that support the management of donor resources, funds, integrations, and related operational processes.

Responsibilities

  • Design, develop, and maintain backend services and RESTful APIs using .NET 10, C#, and ASP.NET Core in a Microsoft Azure cloud environment.
  • Collaborate closely with frontend developers, product owners, architects, and DevOps engineers to deliver secure, reliable, and maintainable functionality.
  • Integrate internal and external APIs and services using modern authentication, authorization, and secure integration patterns.
  • Write and maintain automated unit and integration tests to support code quality and prevent regressions.
  • Participate in pull requests and code reviews, providing and receiving constructive feedback and following team engineering standards.
  • Troubleshoot application issues and production incidents, contributing to diagnosis, resolution, and root cause analysis. Contribute to CI/CD, application observability, configuration, and deployment practices in cloud environments.
  • Apply established software design principles and patterns such as SOLID and Clean Architecture while collaborating with technical leads and architects.
  • Required Experience Backend Development: Hands-on experience developing and maintaining modern backend applications using .NET 10 and C#, with practical knowledge of API development and integration patterns.
  • Familiarity with Angular or another modern frontend framework is a plus. .NET 10 & ASP.NET Core o Experience building web applications and RESTful APIs using ASP.NET Core on .NET 10.
  • Familiarity with modern .NET development practices, including dependency injection, asynchronous programming, configuration, and structured logging. o Understanding of common performance considerations such as caching, efficient I/O, and query optimization.
  • Entity Framework Core 10: Experience with EF Core 10, including migrations, LINQ, relationships, and efficient data-access patterns.
  • Microsoft Azure Cloud o Experience deploying or supporting modern applications using Azure services such as App Service, Azure Functions, Azure SQL, Azure Service Bus, or equivalent PaaS services. o Familiarity with cloud configuration, managed identities, application settings, networking concepts, and observability in Azure. Testing & Debugging
  • Experience writing automated unit and integration tests using current .NET testing frameworks and libraries such as xUnit, NUnit, or Moq.
  • Comfortable using modern debugging, profiling, logging, and diagnostic tools for .NET applications.
  • API Development & Integration
  • Working knowledge of RESTful APIs, HTTP methods, status codes, versioning, and common API integration patterns.
  • Experience with OpenAPI/Swagger and API lifecycle practices; familiarity with Azure API Management is a plus.
  • Experience integrating APIs and implementing secure authentication and authorization using OAuth 2.0, OpenID Connect, and JWT.
  • Modern Identity & Authentication o Familiarity with Microsoft Entra ID and Microsoft Entra External ID for modern identity and access scenarios.
  • Understanding of OAuth 2.0, OpenID Connect, application registrations, scopes, roles, and managed identities. Version Control
  • Experience with Git, including branches, pull requests, merge workflows, and collaborative code reviews.
  • Familiarity with GitHub and repository-based engineering workflows. Application Architecture o Working knowledge of modern distributed application and microservices concepts.
  • Familiarity with Clean Architecture, SOLID principles, dependency inversion, and common software design patterns; exposure to DDD is a plus.
  • Familiarity with Docker and container-based development; exposure to Kubernetes is a plus. o Exposure to event-driven, serverless, or container-based cloud solutions is a plus.
  • Databases: Experience working with Microsoft SQL Server or Azure SQL, including queries, schema changes, indexing basics, and troubleshooting data-access issues. Infrastructure as Code (IaC): Familiarity with Terraform, Bicep, and Azure CLI for provisioning and managing cloud resources is a plus. CI/CD & DevOps Tooling
  • Familiarity with CI/CD pipelines using GitHub Actions or Azure DevOps.
  • Exposure to automated quality gates, security scanning, dependency scanning, and code-quality tools such as SonarQube is a plus.
  • Preferred Qualifications
  • AI-Assisted Development Tools: Familiarity with OpenAI Codex, Claude Code, GitHub Copilot, or similar AI coding assistants is a plus.
